# 🚀 Portfolio - Ricky Perera

Full-stack portfolio website built with the MERN stack, featuring dark mode, email notifications, and responsive design.

🔗 **Live:** [ricca.dev](https://www.ricca.dev)

## ✨ Features

- Modern UI with dark/light mode
- Contact form with email notifications
- Project showcase with pagination
- Fully responsive design
- SEO optimized

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Framer Motion  
**Backend:** Node.js, Express, MongoDB, Nodemailer

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/Ricca20/Portfolio-Ricky.git
cd Portfolio

# Install dependencies
cd frontend && npm install
cd ../backend && npm install

# Configure environment variables
# Create .env file in backend directory with:
# MONGODB_URI, EMAIL_USER, EMAIL_PASS, EMAIL_TO, FRONTEND_URL

# Run development servers
cd frontend && npm run dev  # Port 3000
cd backend && npm start     # Port 5001
```
